ЛеТи — 364 шага к себе (первая мобильная PWA-версия)

Состав:
- index.html — приложение
- manifest.webmanifest — настройки установки на главный экран
- sw.js — офлайн-кэширование
- assets/ — изображения героев и первой истории

Как запустить:
1. Разместите содержимое папки leti-app на HTTPS-хостинге (например, Netlify, GitHub Pages или собственном сайте).
2. Откройте адрес на телефоне.
3. iPhone: Поделиться → На экран «Домой».
   Android: меню браузера → Установить приложение / Добавить на главный экран.

В первой версии работают навигация, первая история, сохранение ответа к практике,
личный дневник в localStorage и отметка прохождения первого дня.
Записи хранятся локально в браузере этого устройства, без синхронизации между устройствами.
Для публикации и общей базы пользователей потребуется отдельный сервер/backend.
