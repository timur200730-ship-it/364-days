ЛеТи — 364 шага к себе · версия 8

Состав:
- index.html — мобильное PWA-приложение
- manifest.webmanifest — параметры установки на экран «Домой»
- sw.js — кэширование для офлайн-доступа
- assets/ — логотип, постоянные герои, 12 тематических обложек и три музыкальные композиции проекта

В этой редакционной сборке опубликованы 12 стартовых историй — по одной для каждого из 12 этапов. У каждой есть художественный текст, психологический смысл, практика и фраза дня. Календарь содержит все 364 дня; золотом отмечаются завершённые опубликованные истории. Остальные дни подготовлены под следующие главы и не заполнены фиктивными текстами. Обложки 12 этапов обновлены единой серией иллюстраций.

Личные записи, ответы практик и прогресс хранятся локально в браузере на конкретном устройстве. Для синхронизации между устройствами понадобится серверная база и авторизация.

В музыкальном разделе доступны три предоставленные оригинальные композиции: «Пока мы верим», «Две чашки кофе», «Вне времени». Аудиофайлы загружаются по запросу и не включены в обязательный первоначальный офлайн-кэш, чтобы не перегружать установку приложения.

Публикация:
1. Загрузить содержимое папки на HTTPS-хостинг (GitHub Pages, Netlify или собственный домен).
2. Проверить, что index.html, manifest.webmanifest, sw.js и assets доступны по одному адресу.
3. Открыть ссылку на iPhone в Safari → «Поделиться» → «На экран Домой».
4. На Android открыть в Chrome → меню → «Установить приложение» / «Добавить на главный экран».

Это PWA, а не нативная сборка App Store/Google Play. Для магазинов приложений потребуется отдельная упаковка и проверка требований площадок.
