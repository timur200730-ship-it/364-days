# Как добавлять истории в приложение «ЛеТи»

## Как устроено приложение
Файл `index.html` содержит данные историй и логику отображения. Истории сгруппированы по главам (12 этапов). На странице «Истории» читатель выбирает главу, затем конкретный день.

## Формат одной истории
Для каждой истории заполняются:
- `day` — номер дня (1–364), уникальный;
- `title` — название истории;
- `story` — массив абзацев рассказа, каждый абзац отдельной строкой;
- `insightTitle` и `insight` — заголовок и абзацы психологического смысла;
- `practiceTitle` — название шага к себе;
- `questions` — список вопросов для дневника (если есть);
- `taskTitle` и `task` — практическое задание;
- `affirmations` — фразы-поддержки (если есть);
- `thoughtTitle` и `thought` — мысль дня;
- `signature` — подпись, если она предусмотрена;
- `image` — путь к иллюстрации (необязательно).

## Как добавлять следующую историю
1. Откройте `index.html` в редакторе кода.
2. Найдите в JavaScript строку `const day2 = {`.
3. Ниже неё находятся данные глав в `const chapters = stages.map(...)`.
4. Новую историю добавляйте в массив `chapters[0].stories` для первой главы или `chapters[1].stories` для второй главы. Запись должна быть объектом в том же формате, что `day2`.
5. Проверьте, что номер дня уникален и попадает в диапазон выбранной главы.
6. Сохраните файл, загрузите его в репозиторий и проверьте опубликованную страницу.

## Редакционный шаблон
```js
{
  day: 3,
  title: 'Название истории',
  chapter: 0,
  image: 'assets/section-01.jpg',
  story: [
    `Первый абзац рассказа.`,
    `Реплика или следующий абзац.`,
    `Финальный абзац.`
  ],
  insightTitle: 'Название психологического смысла',
  insight: [
    `Первый абзац объяснения.`,
    `Второй абзац.`
  ],
  practiceTitle: 'Название шага к себе',
  questions: [
    `Первый вопрос?`,
    `Второй вопрос?`
  ],
  taskTitle: 'Практическое задание на сегодня',
  task: `Короткое описание задания.`,
  affirmations: [`Поддерживающая фраза.`],
  thoughtTitle: 'Мысль дня',
  thought: `Короткий заключительный текст.`,
  signature: 'С любовью, Лея и Тим.'
}
```

Важно: текст истории и психологические формулировки переносить дословно из согласованной рукописи. Не заменять авторский текст пересказом. Абзацы отделять отдельными элементами массива — тогда приложение сохраняет удобный ритм чтения.
